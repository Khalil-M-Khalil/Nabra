# Nabra — نبْرة

## وثيقة تسليم إلى Claude لتصحيح وتطوير التطبيق

> هذه الوثيقة هي شرح كامل للمشروع الحالي والمطلوب من Claude تنفيذه. تعامل معها كمواصفات تطوير واختبار، وليس كمجرد وصف عام.

---

## 1. فكرة المشروع

**Nabra — نبْرة** هو تطبيق Windows يعمل في الخلفية، وظيفته إصلاح النص الذي كُتب باستخدام تخطيط لوحة مفاتيح خاطئ.

مثال:

```
lvpfh
```

هذا النص ناتج عن كتابة كلمة عربية بينما تخطيط لوحة المفاتيح مضبوط على الإنجليزية، والمطلوب تحويله إلى:

```
شكرا
```

مثال آخر:

```
hgsghl ugd;
```

يجب أن يتحول إلى:

```
السلام عليكم
```

التطبيق لا يترجم المعنى ولا يستخدم الذكاء الاصطناعي. هو يقوم بتحويل الأحرف حسب مواضعها في تخطيط لوحة المفاتيح بين العربية والإنجليزية.


## 3. المشكلة التي ظهرت أثناء التجربة

كان الاختصار الأصلي:

```
Ctrl + K
```

لكن هذا الاختصار محجوز في Microsoft Word لإدراج رابط، لذلك عند الضغط عليه ينفذ Word اختصاره الداخلي.

تم تغييره مؤقتًا إلى:

```
Ctrl + Alt + K
```

لكن المطلوب الآن هو جعل الاختصار **قابلًا للتغيير بالكامل من قبل المستخدم**.

يجب ألا يكون الاختصار ثابتًا داخل الكود.

---

## 4. الوظائف المطلوبة في النسخة الجديدة

### 4.1 التحويل الأساسي

عندما يكون التطبيق فعالًا:

1. المستخدم يفتح أي تطبيق يدعم الكتابة، مثل Word أو Notepad أو Chrome.

1. يكتب نصًا بتخطيط لوحة مفاتيح خاطئ.

1. يحدد النص.

1. يضغط الاختصار الذي اختاره داخل Nabra.

1. ينسخ Nabra النص المحدد محليًا.

1. يحدد اتجاه التحويل تلقائيًا.

1. يحول النص بين التخطيط الإنجليزي والعربي.

1. يلصق النص المصحح مكان النص المحدد.

1. يستعيد محتوى الحافظة السابق إن كان ذلك ممكنًا.

### 4.2 مثال متوقع

```
Input:  lvpfh
Output: شكرا
```

```
Input:  hgsghl ugd;
Output: السلام عليكم
```

### 4.3 دعم الاتجاهين

يجب دعم:

- English keyboard layout → Arabic keyboard layout.

- Arabic keyboard layout → English keyboard layout.

ويجب توفير ثلاثة أوضاع في الإعدادات:

- اكتشاف تلقائي.

- دائمًا إلى العربية.

- دائمًا إلى الإنجليزية.

## 5. ميزة اختيار الاختصار — مطلوبة بشكل أساسي

يجب أن يستطيع المستخدم اختيار الاختصار بنفسه من واجهة التطبيق.

### السلوك المطلوب

داخل صفحة أو نافذة **الاختصارات**:

1. يعرض التطبيق الاختصار الحالي، مثل:

```
Ctrl + Alt + K
```

1. يوجد زر:

```
تغيير الاختصار
```

1. عند الضغط عليه تظهر نافذة صغيرة تقول:

```
اضغط تركيبة المفاتيح الجديدة الآن
```

1. يضغط المستخدم أي تركيبة تحتوي على Modifier واحد على الأقل، مثل:

```
Ctrl + Shift + K
Alt + Shift + N
Ctrl + Alt + Space
Ctrl + Alt + Shift + N
```

1. يعرض التطبيق التركيبة التي التقطها.

1. يضغط المستخدم **حفظ** أو **تطبيق**.

1. يلغي التطبيق الاختصار القديم.

1. يسجل الاختصار الجديد عبر Windows RegisterHotKey.

1. إذا كان الاختصار مستخدمًا من تطبيق آخر، يعرض رسالة واضحة:

```
هذا الاختصار مستخدم من تطبيق آخر. اختر تركيبة مختلفة.
```

1. إذا نجح التسجيل، يحفظ الاختصار محليًا حتى بعد إغلاق التطبيق وإعادة تشغيله.

### شروط الاختصار

- يجب منع حفظ مفتاح منفرد دون Modifier.

- يجب دعم Control وAlt وShift وWindows.

- يجب منع الاختصارات الخطرة أو الشائعة جدًا إن أمكن.

- يجب اكتشاف فشل التسجيل بدل عرض نجاح كاذب.

- يجب أن يستطيع المستخدم استعادة الاختصار الافتراضي.

- الاختصار الافتراضي المقترح:

```
Ctrl + Alt + K
```

### التخزين

احفظ الاختصار في ملف إعدادات محلي، مثل:

```json
{
  "hotkey": {
    "modifiers": ["Control", "Alt"],
    "key": "K"
  },
  "conversionMode": "auto",
  "isEnabled": true,
  "restoreClipboard": true
}
```

لا تستخدم قاعدة بيانات أو خدمة سحابية لهذه الإعدادات.

## 6. مشكلة الحافظة التي يجب إصلاحها

في النسخة السابقة، عند تحديد النص `lvpfh` والضغط على الاختصار، ظهر حرف `c` بدل النص الصحيح. السبب المحتمل هو أن التطبيق قرأ محتوى قديمًا من الحافظة قبل اكتمال عملية النسخ.

يجب تنفيذ العملية بهذا التسلسل:

1. حفظ محتوى الحافظة السابق في الذاكرة.

1. تفريغ الحافظة فعليًا.

1. إرسال `Ctrl + C` إلى التطبيق النشط.

1. الانتظار حتى يتم تحديث الحافظة.

1. التحقق من أن الحافظة تحتوي على نص جديد.

1. قراءة النص المحدد.

1. رفض العملية إذا كان النص فارغًا أو لم يتغير.

1. تحويل النص.

1. وضع النص المحول في الحافظة.

1. إرسال `Ctrl + V` إلى التطبيق النشط.

1. الانتظار حتى يكتمل اللصق.

1. استعادة الحافظة السابقة إن كان الخيار مفعّلًا.

### مهم جدًا

- يجب تنفيذ Clipboard على خيط STA مناسب.

- يجب ألا يتم استخدام محتوى قديم من الحافظة.

- يجب التعامل مع فشل النسخ أو اللصق بهدوء.

- لا تحفظ النصوص في ملفات Log.

- لا ترسل النصوص إلى الإنترنت.

- لا تستخدم API ذكاء اصطناعي أو ترجمة خارجية.

## 7. آلية التحويل

يجب بناء جدول تخطيط لوحة مفاتيح عربي/إنجليزي صحيح ومتوافق مع Windows Arabic 101/102 حسب التخطيط المستهدف.

الجدول الحالي تقريبي ويجب مراجعته وتصحيحه.

يجب اختبار الأحرف الأساسية، ومنها:

```
q w e r t y u i o p
 a s d f g h j k l
  z x c v b n m
```

يجب اختبار حالات Shift وعلامات الترقيم، وعدم تغيير:

- المسافات.

- الأسطر الجديدة.

- الأرقام إلا إذا كان ذلك جزءًا من التخطيط.

- الروابط.

- البريد الإلكتروني.

- الرموز غير المدعومة.

يجب الحفاظ على النص المختلط قدر الإمكان.

- اختيار وضع التحويل.

## 10. الخصوصية

هذه متطلبات إلزامية:

- لا يوجد Backend.

- لا يوجد تسجيل دخول.

- لا يوجد اتصال بالإنترنت.

- لا يتم رفع النصوص.

- لا يتم حفظ النصوص المحولة.

- لا يتم تسجيل ضغطات المفاتيح العادية.

- يتم التقاط الاختصار المسجل فقط.

- كل المعالجة محلية على الجهاز.

يجب تجنب تشغيل التطبيق بصلاحيات Administrator إلا عند الضرورة.

## 11. التقنية المقترحة

الخيار المفضل:

- C#.

- .NET 8 أو أحدث.

- Windows Forms أو WPF.

- Windows RegisterHotKey.

- Clipboard API.

- SendInput أو طريقة موثوقة لإرسال Ctrl+C وCtrl+V.

- JSON محلي للإعدادات.

لا تضف مكتبات خارجية إلا إذا كانت ضرورية جدًا.

إذا كان استخدام WPF يسبب مشاكل في بيئة البناء، يمكن استخدام Windows Forms مؤقتًا، لكن حافظ على فصل الخدمات عن الواجهة:

```
KeyboardLayoutService
HotkeyService
ClipboardService
SettingsService
DirectionDetectionService
```

1. اختبر عدم فقدان محتوى الحافظة.

## 13. معايير القبول

يُعتبر العمل ناجحًا إذا تحققت الشروط التالية:

- يحدد المستخدم `lvpfh` داخل Notepad أو Word.

- يضغط الاختصار.

- يحصل على `شكرا`.

- يستطيع المستخدم تغيير الاختصار من داخل التطبيق.

- يعمل الاختصار الجديد بعد حفظه فورًا.

- لا يتعارض الاختصار مع Word دون إظهار رسالة.

- لا يظهر حرف قديم من الحافظة.

- لا تضيع الحافظة السابقة.

- يعمل التطبيق في الخلفية.

- لا يتم إرسال أي نص إلى الإنترنت.

- يمكن تعطيل التطبيق وإعادة تفعيله.

- يتم حفظ الاختصار بعد إعادة تشغيل التطبيق.

## 14. تنبيه مهم حول تجربة Word

لا تعتمد على `Ctrl + K` لأنه اختصار محجوز في Word.

استخدم مبدئيًا:

```
Ctrl + Alt + K
```

ثم اختبر ميزة اختيار اختصار مخصص من داخل التطبيق.
